# FROST UFA — первый пример

Две страницы одной системы: `index.html` (ремонт на дому) и `business.html` (для организаций). Статический HTML/CSS/JS, без сборки. Исходные вложения сохранены в родительской папке без изменений.

Открыть локально: `python -m http.server 8080 --directory "FROST UFA/preview"`, затем http://localhost:8080. Папку `preview` можно целиком опубликовать через GitHub Pages. Montserrat загружается из Google Fonts; при отсутствии сети используется Arial.

Работают переключение страниц, открытие дверцы, выбор симптома/оборудования, перенос выбора в форму, подготовка и копирование обращения. Форма ничего не отправляет и не сохраняет; подготовленный текст можно вручную отправить в Telegram @frostufa. Номер +7 (347) 000-00-00 — обозначенный на сайте временный пример, без ссылки для звонка. VK frostufa отмечен «скоро» без активной ссылки. Точный адрес, отзывы и история прежнего владельца домена не выдуманы.

Кнопка «Вызвать мастера» в шапке открывает окно выбора связи: подготовка запроса на обратный звонок, пока неактивный звонок по телефону и Telegram. Для обратного звонка поле телефона становится обязательным, номер включается в текст обращения. Пользователь самостоятельно отправляет этот текст в Telegram; серверного приёма и автоматического обратного звонка пока нет.

Форма находится в отдельном модальном окне, а не в основной странице. В неё ведут кнопки первого экрана, команды и карты, выбор поломки и пункты верхнего окна связи. На прежнем месте формы — авторская схематичная SVG-карта Уфы с лучом радара и декоративными точками зоны выезда. Это не навигационная карта, не граница точного радиуса и не отслеживание мастеров/заявок. Анимация отключается при уменьшении движения.

Дисплей холодильника демонстрирует поломку: на светлой странице температура повышается от −18 до +20 °C, на бизнес-странице — от +4 до +20 °C. В конце появляется предупреждение, состояние сохраняется до открытия дверцы. Открытие сбрасывает температуру и показывает восстановление холода; пока дверь открыта, нагрев остановлен. Таймеры приостанавливаются в скрытой вкладке. При уменьшении движения поломка показана статично, открытие по-прежнему восстанавливает холод. Это декоративная демонстрация, а не инструкция по ремонту.

Следующий этап: подтверждённые контакты, серверный приём заявок в Telegram, согласие на обработку данных и ИИ-консультант. Токен Telegram и ключ ИИ должны храниться на сервере. Историю домена перед использованием в SEO нужно проверить отдельно.

Сезонный фон выбирается по календарю Уфы: декабрь–февраль — снег, июнь–август — солнце, остальные месяцы — дождь. Предпросмотр: `?season=winter`, `?season=summer`, `?season=spring`, `?season=autumn`. Анимация скрывается при настройке уменьшения движения, приостанавливается в скрытой вкладке; фон не перехватывает нажатия и не использует геолокацию.

`master-1.html` — профиль Рината Нуркаева, руководителя FROST UFA: опыт 8 лет, высшее образование в области программирования, профильные курсы. `master-2.html` — Радмир Насыров: общий опыт 8 лет, из них 6 с промышленными холодильниками, по образованию экономист. В профессию пришёл после знакомства с мастером, ремонтировавшим его домашний холодильник. Карточки обоих мастеров есть на светлой и тёмной главных страницах. Сканы грамот пока не получены; документы не выдуманы. `master-3.html` остаётся обозначенным шаблоном с noindex.

Портреты `assets/rinat-uniform.jpg` и `assets/radmir-uniform.jpg` обработаны встроенным imagegen по присланным изображениям: фирменная чёрная форма с оранжевыми вставками взята из айдентики, рекламные плашки удалены. Это изображения с обработкой ИИ. Исходные рекламные обещания и телефон из изображения Радмира не перенесены в сайт. JPEG 600×800 подготовлены для веба, исходные PNG сохранены локально в `portraits-source`.

В профилях размещены 11 присланных пользователем JPEG-макетов: по 5 именных образцов у Рината и Радмира, плюс одна общая благодарность FROST UFA на обеих страницах. По запросу владельца в галереях убраны пояснение о демонстрационных макетах и метки «Образец». Размер изображений — 960×1280. Исходные файлы скопированы без изменения. `documents.js` отключает контекстное меню, перетаскивание, выделение и события копирования/вырезания у превью документов; увеличение и прямые ссылки с карточек отсутствуют. CSS отключает стандартное меню долгого нажатия на iOS и скрывает изображения документов при печати и сохранении страницы в PDF. Файлы остаются доступны браузеру и в публичном репозитории. Настоящие документы будут добавлены после получения сканов.
