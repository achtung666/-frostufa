# FROST UFA — первый пример

Две страницы одной системы: `index.html` (ремонт на дому) и `business.html` (для организаций). Статический HTML/CSS/JS, без сборки. Исходные вложения сохранены в родительской папке без изменений.

Открыть локально: `python -m http.server 8080 --directory "FROST UFA/preview"`, затем http://localhost:8080. Папку `preview` можно целиком опубликовать через GitHub Pages. Montserrat загружается из Google Fonts; при отсутствии сети используется Arial.

Работают переключение страниц, открытие дверцы, выбор симптома/оборудования, перенос выбора в форму, подготовка и копирование обращения. Форма ничего не отправляет и не сохраняет; подготовленный текст можно вручную отправить в Telegram @frostufa. Номер +7 (347) 000-00-00 — обозначенный на сайте временный пример, без ссылки для звонка. VK frostufa отмечен «скоро» без активной ссылки. Точный адрес, отзывы и история прежнего владельца домена не выдуманы.

Кнопка «Вызвать мастера» в шапке открывает окно выбора связи: подготовка запроса на обратный звонок, пока неактивный звонок по телефону и Telegram. Для обратного звонка поле телефона становится обязательным, номер включается в текст обращения. Пользователь самостоятельно отправляет этот текст в Telegram; серверного приёма и автоматического обратного звонка пока нет.

Следующий этап: подтверждённые контакты, серверный приём заявок в Telegram, согласие на обработку данных и ИИ-консультант. Токен Telegram и ключ ИИ должны храниться на сервере. Историю домена перед использованием в SEO нужно проверить отдельно.

Сезонный фон выбирается по календарю Уфы: декабрь–февраль — снег, июнь–август — солнце, остальные месяцы — дождь. Предпросмотр: `?season=winter`, `?season=summer`, `?season=spring`, `?season=autumn`. Анимация скрывается при настройке уменьшения движения, приостанавливается в скрытой вкладке; фон не перехватывает нажатия и не использует геолокацию.

`master-1.html` — профиль Рината Нуркаева, руководителя FROST UFA: опыт 8 лет, высшее образование в области программирования, профильные курсы. На обеих главных страницах есть карточка со ссылкой на профиль. Портрет показывается фрагментом присланного рекламного изображения; рекламные обещания с него в тексты не перенесены. Сканы грамот пока не получены. `master-2.html` и `master-3.html` остаются обозначенными шаблонами, закрытыми от индексации и не включёнными в публичную команду.
